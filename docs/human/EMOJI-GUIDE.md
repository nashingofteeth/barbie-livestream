# Custom Barbie Emojis Guide

This directory will contain your custom Barbie-themed emojis for the Owncast chat.

## Required Emojis

Create or download the following emoji images (PNG format, transparent background recommended):

### 1. sparkle.png
- Pink or gold sparkle/star
- Suggested size: 32x32px or 64x64px
- Keywords: sparkle, shine, glitter

### 2. heart.png
- Pink or hot pink heart
- Suggested size: 32x32px or 64x64px
- Keywords: heart, love, pink

### 3. crown.png
- Gold or pink tiara/crown
- Suggested size: 32x32px or 64x64px
- Keywords: crown, princess, tiara

### 4. star.png
- Pink five-point star
- Suggested size: 32x32px or 64x64px
- Keywords: star, favorite, magic

### 5. wand.png
- Magic wand with sparkles
- Suggested size: 32x32px or 64x64px
- Keywords: wand, magic, fairy

### 6. kiss.png
- Pink lipstick kiss mark
- Suggested size: 32x32px or 64x64px
- Keywords: kiss, lips, love

## How to Add Emojis to Owncast

1. Create or download the emoji images
2. Save them in this directory (`data/emoji/`)
3. Start your Owncast server
4. Go to the admin panel: `http://localhost:8080/admin`
5. Navigate to **General** > **Chat**
6. Scroll to **Custom Emoji** section
7. Click **Add Emoji**
8. For each emoji:
   - Upload the image file
   - Enter the emoji name (e.g., "sparkle")
   - Add keywords for autocomplete
   - Save

## Image Specifications

- **Format**: PNG (with transparency preferred)
- **Size**: 32x32px to 128x128px (64x64px recommended)
- **File size**: Under 100KB each
- **Color**: Use Barbie theme colors (#FF69B4, #FFD700, #FFB6C1)

## Where to Find Emoji Images

### Free Resources:
- **Flaticon** (https://www.flaticon.com) - Search for "crown", "sparkle", "heart"
- **Icons8** (https://icons8.com) - Pink-themed icons
- **Noun Project** (https://thenounproject.com) - Simple icons

### Create Your Own:
- Use Canva to design custom emojis
- Use Photoshop or GIMP with pink color palette
- Convert existing emojis to pink theme

## Testing Emojis

After adding emojis to Owncast:
1. Open your stream page
2. Join the chat
3. Type `:` followed by the emoji name (e.g., `:sparkle:`)
4. The emoji should appear in the autocomplete
5. Send a message to see it display

## Emoji Usage Tips

Users can type:
- `:sparkle:` → sparkle emoji
- `:heart:` → heart emoji
- `:crown:` → crown emoji
- etc.

Make sure to tell your viewers about the custom emojis!
